A comprehensive manual testing project for the OpenCart e-commerce platform. This repository contains detailed test scenarios, test cases, and bug reports designed to ensure a seamless user experience.


📌 Project Overview


The objective of this project is to validate the core functionalities of OpenCart using manual testing techniques. I have documented positive and negative test cases to cover end-to-end user workflows, from registration to checkout.


Platform Tested: OpenCart Demo Site


Testing Type: Functional, UI/UX, and Regression Testing.


Format: Documentation is provided in .docs formats.
